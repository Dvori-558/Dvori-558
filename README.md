## 🤖 AI Projects

### [TaskMaster AI Assistant: Event-Driven RAG System](https://github.com/Dvori-558/rag-with-llamaindex)
An AI agent that indexes project documentation, specs, and technical decisions and answers questions about them in natural language. Requests go through an asynchronous event-driven workflow with validation and postprocessing. A router decides per question between vector search and a structured-data engine built from Pydantic-extracted JSON, which keeps factual answers free of hallucinations.
`Python` `LlamaIndex` `Pydantic` `Gradio`

### [Career Navigator: Claude Agent, API vs. SDK](https://github.com/Dvori-558/claude-agent-api-vs-sdk)
An AI career coach and job tracker built twice: once on the raw Claude Messages API with a custom agent harness, and once with the Claude SDK, which needed 42% less code. The project compares the two agent architectures side by side.
`Python` `Claude API` `Claude SDK`

### [Israel Weather MCP Server](https://github.com/Dvori-558/israel-weather-mcp)
An MCP server that exposes tools for getting weather forecasts for cities in Israel. Instead of calling an API, it uses Playwright to drive a browser like a human user, so the LLM can take real actions to collect information.
`Python` `MCP SDK` `Playwright`

### [NotebookLM Lite: Autonomous Research Agent](https://github.com/Dvori-558/notebooklm-lite)
A graph-based research agent that searches the web in real time, pauses for human-in-the-loop approval of sources, and writes a summary in Hebrew with Llama 3.3 70B on Groq. It includes state management with LangGraph's MemorySaver and a full RTL Streamlit UI.
`Python` `LangGraph` `LangChain` `Groq` `Tavily` `Streamlit`
